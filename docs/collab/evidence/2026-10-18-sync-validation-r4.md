## 3. Q-014：无法定位的切点

- **现象**：20260903 全局摄像机的第一个切点，粗位置 b = 961.25 秒。前后相邻有效长窗的中心分别为 811.15 秒与 1111.35 秒。细化用的 23 个短窗全部无效，条图显示该段工位无人。
- **决定（推广到所有切点）**：每个切点的不确定区间，从切点前最近的有效窗中心，到切点后最近的有效窗中心，两端各再加该窗长度的一半。有效窗包括 60 秒长窗与 20 秒细化短窗。
  - 细化成功时区间很窄；细化窗全部无效时，该切点记为“未定位”，区间延伸到两侧相邻的有效长窗。
  - 区间内的网格步全部标为 `sync_uncertain`，抽样排除与之重叠的片段。
  - 这条规则同时回应了独立审查的另一个发现：分段规则可能在无证据的空档两侧，用斜率自由的最小中段做外推。不改拟合，而把切点与最近证据之间的整段视为不确定，因此不需要重新拟合或重建代理；凡有证据的地方，验证都已通过。
- **影响**（Codex 的只读分析）：该会话的不确定步由 202 增至 1,903，约 6.3 分钟；按固定种子抽中的 4 个片段起点不变，不需要重抽。
- **理由**：没有数据能确定台阶发生在这 5 分钟里的哪一刻，诚实的做法是把整段视为不确定，而不是把 ±10 秒的规定区间当成已知精度。该段无人，排除它对标注的损失很小。

## 4. Q-015：时钟抽查的同源帧补读

- **现象**：20260911 全局摄像机 k = 15804 及其前后各两帧，在代理帧上都读不出，原因是分钟个位字形误差 0.246，超过 0.18 的阈值。同一源帧（PTS 3167.568 秒）读出 2026-09-07T22:52:27，最大误差 0.175、最小余量 0.073，d = +0.023 秒，落在理想区间 [0, 1) 内。
- **决定**：读数顺序为
  1. 代理帧 k；
  2. 它所用的源帧（按旁注中的源文件与 PTS 解码，PTS 必须完全一致）；
  3. 代理帧 k−1，然后它的源帧；
  4. k+1、k−2、k+2，依此类推。

  每个读数记录取自代理还是源帧，以及代理帧与源帧缩略图的平均差。识别阈值、固定 k、通过区间与“可评估比例不低于 90%”都不变。
- **理由**：抽查的对象是映射与选帧，即这一网格步所用的源帧，其显示时钟是否与映射一致。从同一源帧读，检验的是同一件事，只是避开了代理缩放与编码造成的字形损失。代理帧与源帧是否同一帧，由旁注来源与事件条图的逐像素核对保证。
