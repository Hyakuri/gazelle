1. **运动能量的关键帧屏蔽**（校准与验证共用同一实现）：
   - **关键帧来源**：每个源文件视频流的包标记，读取整个文件，只解复用、不解码，可用 PyAV 或 `ffprobe`。全局摄像机使用重封装文件。结果按源文件 SHA、大小与修改时间缓存。
   - **屏蔽规则**：第 k 步的能量来自第 k−1 步与第 k 步所选两帧之差。出现以下任一情况时，该步能量记为缺失；缺口步照旧记为缺失：
     - 两帧来自不同源文件；
     - 存在源关键帧 p，满足 pts[k−1] < p ≤ pts[k]。
   - **代理上的验证**：另外按代理文件自身的关键帧，用同一规则再屏蔽一次。
   - **报告**：每台摄像机被屏蔽的步占比。参考值为：关键帧间隔 2.5 秒约 8%，2.0 秒约 10%，全局摄像机 4.0 秒约 5%。

     | --- | --- | --- | --- |
     | 10.00 | 10.20 | 10.20 | 屏蔽：新帧是关键帧 |
     | 10.00 | 10.20 | 10.12 | 屏蔽：两帧之间跨过关键帧 |
     | 10.00 | 10.20 | 10.00 | 不屏蔽：关键帧是旧帧 |
     | 10.00 | 10.20 | 10.40 | 不屏蔽 |

4. **分段规则**（Q-012 第 1 项）：
   - 输入：某摄像机的有效窗 (t_i, L_i)，按时间排序，共 n 个。
   - **门槛 G**，以下各条同时满足才合格：
     - n ≥ 10；
     - 有效窗覆盖会话时长的 30% 以上；
     - 每段至少 5 个有效窗；
     - 全部残差的 MAD ≤ 0.08 秒；
     - |残差| > 0.2 秒的窗不超过 10%。
   - **搜索**：
     1. 从整段一条 Theil–Sen 直线开始。
     2. 在当前每一段内，枚举两类候选：一刀切成两部分，两侧各至少 5 窗；或同一段内切两刀成三部分，各至少 5 窗，用于中间隆起。总切点数不超过 3。
     3. 每部分各自拟合 Theil–Sen 直线，代价为残差绝对值之和（L1）。下降比例 = (原段代价 − 候选代价) / 原段代价。
     4. 候选可接受的条件是两条同时满足：
        - 下降比例 ≥ 0.25；
        - 每个新切点处，两侧直线在切点时间上的差 |ΔL| ≥ max(0.2 秒, 4 × 该候选在原段内残差的 MAD)。切点时间取两侧相邻有效窗的中点。
     5. 每次接受下降比例最大的可接受候选。重复第 2 至 4 步，直到没有可接受的候选，或已有 3 个切点。
     6. 不论门槛是否已经满足，都要执行这一搜索，因为一半一半的台阶可能以单一直线勉强通过门槛。

5. **台阶处的映射**（Q-012 第 2 项）：
   - **自变量**：校准量改为该摄像机自身基础时间 b 的函数。每个有效窗的中心换算为 b_c = t_c + L_c，在 b 上拟合与分段，规则同第 4 条。
   - **最终时间**：T(b) = b − L(b)，逐帧显式计算，不再做不动点迭代。只有一段时，与现行结果之差不超过 |c1|·|L|，实际约 1e-6 秒以内。
   - **切点处**：设切点为 b_j，ΔL = L(b_j 之后) − L(b_j 之前)。
     - ΔL < 0：T 向前跳 |ΔL|，形成覆盖缺口。网格步按现行“最近帧 + 半步长缺口”规则处理。
     - ΔL > 0：T 回退 ΔL，形成重叠。切点之前、T 不小于切点之后第一帧 T 的那些帧，不参与选帧，使可选帧的 T 严格递增。
   - **不确定标记**：以下网格步在旁注中标为 `sync_uncertain: true`：
     - 切点不确定区间（±10 秒）内的网格步；
     - 缺口或重叠范围内的网格步。
   - **示例**（需写成测试）：

     | 情形 | 帧 b | T | 说明 |
     | --- | --- | --- | --- |
     | ΔL = +0.4，b_j = 100，之前 L = 0 | 99.9 | 99.9 | 若 T ≥ 99.6，不参与选帧 |
     | 同上 | 100.0 | 99.6 | 切点后第一帧 |
     | ΔL = −0.4，b_j = 100，之前 L = 0 | 99.9 | 99.9 | |
     | 同上 | 100.0 | 100.4 | (99.9, 100.4) 之间为缺口 |
